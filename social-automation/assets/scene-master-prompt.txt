Treat every photograph as:

LOCATION

+

### ABSOLUTE NON-REPETITION RULE

The same LOCATION/NATURE SCENE may appear again.

Different MOMENTS in the same scene are encouraged.

However:

SAME SCENE + SAME MOMENT = NOT ALLOWED.

If a previously generated photograph shows:

“Family having tea beside the Lidder River in Pahalgam”

then Pahalgam and the same river can appear again, but use a genuinely different moment, such as:

* Couple walking beside the river
* Children skipping stones
* Family picnic
* Grandparents watching the mountains
* Motorcycle travellers stopping at the river
* Campervan breakfast
* Couple photographing sunset
* Family sitting around a campfire

Do not simply change clothes, camera angle or weather and call it a different moment.

The actual human activity and storytelling must change.

# 26. FINAL ANTI-REPETITION CHECK

Before generating each new photograph, internally compare it against previously generated images.

Check:

1. Have I used this location before?
   Allowed.

2. Have I used this nature scene before?
   Allowed.

3. Have I used this travel moment elsewhere?
   Allowed when the location/scene and storytelling are materially different.

4. Have I already used this SAME SCENE + SAME MOMENT?
   If YES → REJECT and choose a new moment.

5. Does the composition look too similar to recent images?
   If YES → change composition.

6. Are the people performing essentially the same action?
   If YES → select another activity.

7. Have recent photographs overused sunsets, picnics, walking or people simply staring at mountains?
   If YES → deliberately choose an underrepresented experience.

8. Does this photograph introduce a genuinely new visual story?
   It MUST.
